## Categories

### 1. RCE & Web Enumeration
Explore the relationship between web reconnaissance, enumeration, exposed functionality, and remote code execution through labs such as **Web RCE to User Flag** and **RCE by Enumeration**.

### 2. Information Disclosure & Configuration Security
Practice identifying security-relevant information in configuration files, hidden locations, database queries, and exposed application data.

### 3. Linux Users, Paths & Permissions
Build practical understanding of Linux user discovery, filesystem paths, permission boundaries, and potentially exposed resources.

### 4. Command Injection
Study **OS command injection**, shell command execution, parameter-driven behavior, and RCE-oriented application weaknesses in controlled CTF environments.

## Learning Path

A practical progression is:

1. Start with **Paths and Permissions** and **Enum Trail Linux User Hunt**.
2. Continue with **Config Leak Hunter** and **Config Hunt Hidden Files**.
3. Study **Hidden Files Loud Breaches** and **Query Leak DB Secrets**.
4. Practice parameter-focused investigation with **Param Pulse**.
5. Move into **RCE by Enumeration** and **Web RCE to User Flag**.
6. Finish with the **Search Shell Command Injection**, **Injection Trail OS Command RCE**, and **Command Injection Unleashed** labs.

This progression moves from reconnaissance and information discovery toward web exploitation concepts and command-injection vulnerabilities.

## How to Use the Labs

- Use these labs only in authorized learning environments.
- Read each lab objective before beginning.
- Practice systematic enumeration rather than relying on random payloads.
- Record discovered paths, parameters, technologies, and security observations.
- For command-injection exercises, understand why an input becomes dangerous rather than only reproducing the result.
- Compare offensive findings with defensive controls such as input validation, least privilege, secure configuration, and safe command execution.
- Document lessons learned for future penetration testing and vulnerability assessment work.
